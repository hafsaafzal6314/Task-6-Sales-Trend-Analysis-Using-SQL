# 📊 Sales Trend Analysis Using SQL

## 📌 Project Overview

This project analyzes sales data using SQL aggregation techniques to identify monthly sales trends. The analysis focuses on calculating monthly revenue and order volume using MySQL. It demonstrates the use of SQL functions for grouping, sorting, and summarizing business data.

---

## 🎯 Objective

- Analyze monthly revenue.
- Analyze monthly order volume.
- Group data by year and month.
- Identify the highest revenue months.
- Practice SQL aggregation functions for business analysis.

---

## 🛠️ Tools & Technologies

- MySQL Workbench
- SQL
- CSV Dataset

---

## 📂 Dataset

**Dataset Name:** `online_sales.csv`

### Columns

- `order_id` – Unique order identifier
- `order_date` – Date of the order
- `amount` – Sales amount
- `product_id` – Product identifier

---

## 📈 SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- SUM()
- COUNT(DISTINCT)
- YEAR()
- MONTH()
- LIMIT

---

## 📊 Analysis Performed

- Displayed sample sales records.
- Calculated monthly revenue.
- Calculated monthly order volume.
- Combined revenue and order volume in a single report.
- Filtered data for a specific year.
- Identified the top 6 revenue-generating months.
- Found the highest revenue month.
